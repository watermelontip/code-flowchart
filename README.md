# 代码转流程图 - Code to Flowchart

将代码自动转换为 SVG 流程图的在线工具。

## 🌐 在线演示

👉 [点击访问在线演示](https://watermelontip.github.io/code-flowchart/)

## ✨ 功能特性

- **多语言支持**：Python、JavaScript、C 语言伪代码
- **智能解析**：自动识别 if/else、for、while、函数、return 等结构
- **标准流程图形状**：矩形(处理)、菱形(判断)、平行四边形(I/O)、圆角矩形(开始/结束)
- **自动布局**：自动排列节点并连线
- **代码编辑器**：行号显示、Tab 缩进、快捷键支持
- **缩放控制**：滑块缩放、适应视图、鼠标滚轮缩放(Ctrl+滚轮)
- **导出功能**：导出 SVG 矢量图 / PNG 位图
- **示例代码**：斐波那契、冒泡排序、二分查找、最大公约数、阶乘
- **暗色主题**：现代深色 UI
- **中文界面**
- **响应式设计**：适配桌面和移动设备
- **零依赖**：纯 HTML/CSS/JavaScript，单文件实现

## 🚀 使用方法

1. 选择编程语言
2. 输入代码或选择示例
3. 点击「生成流程图」或按 `Ctrl + Enter`
4. 使用缩放控件调整视图
5. 导出为 SVG 或 PNG

## 📋 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl + Enter` | 生成流程图 |
| `Tab` | 插入缩进 |
| `Ctrl + 滚轮` | 缩放流程图 |
